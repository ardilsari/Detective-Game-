# Detective Game - Jack the Ripper

Ünlü cinayetlerin çözülmesi temasında yapılan interaktif detective oyunu.

## Oyun Hakkında

Oyuncu dedektif rolü alarak:
- Tanıkları sorgular
- Kanıtları toplar
- Suçluyu bulur
- Davayı çözer

## Teknoloji

- **Engine:** Unity
- **Language:** C#
- **Platform:** PC (Steam)
- **Dil:** Türkçe

## Oyun Mekanikler

### 1. Detective Masası (Main UI)
- Tanık fotoğrafları
- Harita
- Kanıt listesi
- Notlar

### 2. Veritabanı Sistemi
- Tanık araması
- Dosya taraması
- Otopsi raporları

### 3. Sorgulama Sistemi
- Tanıklarla konuşma
- İpuçları toplama
- Kanıt bağlantıları

### 4. Sonuç Sistemi
- Suçluyu seç
- Doğru/yanlış sonuç
- Puan sistemi
